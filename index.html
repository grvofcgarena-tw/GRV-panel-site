JAVASCRIPT · DISCORD VOICE · AUDIO TOOLING

把即時音訊工具

GRV 是一套以 Node.js 為核心的 Discord 音訊工具實作，示範 yt-dlp、FFmpeg、@discordjs/voice、PCM mixing、語音 AI 與 E2EE voice transport 如何協同運作。

查看技術架構 閱讀原始碼
grv-audio.js
const pipeline = new AudioPipeline({
  source: 'yt-dlp',
  decoder: 'ffmpeg',
  transport: 'discord-voice',
  encryption: 'dave/e2ee'
});

await pipeline.play(track);

WHY IT EXISTS

一個可拆解、可測試的音訊管線

01

直接串流

以 yt-dlp 取得合法公開影音來源的音訊 URL，交由 FFmpeg 解碼為 48 kHz stereo PCM，再交給 Discord Voice。

02

平滑混音

PCM mixer 以 20 ms frame 混合音樂與語音，透過 ducking gain 讓語音回覆期間音樂降低，結束後平滑恢復。

03

可觀測狀態

播放世代、串流位置、格式、位元率與結束原因都以結構化事件記錄，協助診斷中斷與競態。
